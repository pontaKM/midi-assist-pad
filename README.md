# midi-assist-pad

iPad（Web MIDI Browser）から外部MIDI機材へ、エクスプレッションなどの「表情」を送るための補助ツールです。
キーボード演奏が得意でなくても、ステップ入力したフレーズに、あとから音楽的な抑揚を重ね録りできることを目指しています。

まずは **Yamaha QY300** を対象に作り、のちに electribe 2 や MPC1000 にも広げる予定です。

## 開き方

GitHub Pages で公開しています。iPad の **Web MIDI Browser** で次のアドレスを開いてください。

https://pontakm.github.io/midi-assist-pad/

（iOS 12 の標準 Safari は Web MIDI に対応していないため、Web MIDI Browser などの対応アプリが必要です。）

## 接続（QY300の場合）

```
QY300 MIDI OUT ──> USB-MIDIインターフェース IN ──> iPad（クロック受信）
iPad ──> USB-MIDIインターフェース OUT ──> QY300 MIDI IN（CC送信）
```

- iPad とインターフェースは Lightning-USB カメラアダプタでつなぎます。
- QY300 は MIDI Sync を Internal にし、クロックを送る設定にします。
- 画面上部の **CH** を、録音するトラックのチャンネルに合わせます。

## 機能

画面上部のタブで切り替えます。

| タブ | 内容 |
|---|---|
| フェーダー | 画面幅いっぱいの4本のフェーダー。触った位置から動かした分だけ値が変わります（設定で「触った位置の値にする」にも切替可、感度も選択可）。送り先（Expression / Modulation / Volume / Pan / Pitch Bend / 任意CC）と、指を離したときの動作（保持・戻る）を選べます |
| XY | 大きなXYパッド。横と縦に別々の送り先を割り当てられます |
| オート | 「4小節でクレッシェンド」などを自動で送ります。外部クロック同期時は小節頭から始まり、QY300の停止に合わせて止まります |
| 設定 | MIDI OUT / CLOCK IN / 機材の選択、テスト音、送受信モニター、スムージング、送信間隔の下限、1小節の拍数、任意CCの番号 |

上部の「リセット」で Expression=127、Modulation=0、Pitch Bend=中央 に戻します。設定は次回開いたときも残ります。

**遅れを減らしたいとき**：設定タブのスムージングを0にすると、指の動きをそのまま送ります。

## 自動クレッシェンドを録音する手順

1. QY300 をソングのリアルタイム録音待ちにする
2. AUTO CURVE で送り先・開始値・終了値・長さ・カーブを設定し、**GO** を押す（「待機中」になります）
3. QY300 の録音を開始する → 指定した小節頭からカーブが送られます

## 機材の追加

`index.html` の冒頭にある `PROFILES` に、同じ形で機材を追加すると、画面の「機材」欄で選べるようになります。
